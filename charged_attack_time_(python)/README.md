# Charged Attack Time
Tell how much time it takes to charge an charged attack, based on the immediate attack used. You could give multiple attacks, creating all possible couple.

## Required Actions
- You must download the game master file from the [PokeMiners' Github](https://github.com/PokeMiners/game_masters/tree/master/latest) (take the lastest .json) (since the file is big (i know it's not tht big, but whatever), i prefer not to add it in the repo here)

## Notes
- This repo contain the python program created for this tool (temporarly used before it will be implemented in the app)
- "traduction" files contain the english and french version of the moves. It's a dictionnary, the key is the english version as writen in the gamemaster file, the value is the french version as writen in the game.
